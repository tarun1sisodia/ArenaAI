## Generated variants

Each slide has:

- `480` mobile portrait crop;
- `960` tablet/medium crop;
- `1600` desktop crop;
- WebP and AVIF formats.

The source images were resized and cropped deterministically with FFmpeg. No generative editing, AI upscaling, or image synthesis was used.
