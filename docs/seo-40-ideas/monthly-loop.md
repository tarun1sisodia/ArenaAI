# Monthly SEO Loop (idea 40)
Run on the 1st of every month. Needs Search Console access (idea 9 — pending).

## The loop
1. **GSC Performance → Queries:** export queries where the site ranks positions 8–30. These are the refresh targets — closest to page 1.
2. **Refresh:** for each target query, improve the matching page (add the missing subtopic, tighten the title, add one FAQ from real customer questions). One page per week is plenty.
3. **Rank tracker — 10 target phrases** (update monthly):
   | # | Phrase | Target page |
   |---|---|---|
   | 1 | delhi to agra taxi | /en/delhi-to-agra-taxi/ |
   | 2 | agra to delhi taxi | /en/agra-to-delhi-taxi/ |
   | 3 | delhi airport to agra taxi | /en/delhi-airport-to-agra-taxi/ |
   | 4 | agra to jaipur taxi | /en/agra-to-jaipur-taxi/ |
   | 5 | tempo traveller on rent in agra | /en/tempo-traveller-on-rent-agra/ |
   | 6 | taj mahal taxi service | /en/taj-mahal-taxi-service/ |
   | 7 | taxi near taj mahal | /en/taxi-near-taj-mahal-agra/ |
   | 8 | delhi to agra innova crysta fare | /en/delhi-to-agra-innova-crysta-taxi-fare/ |
   | 9 | agra to mathura taxi | /en/agra-to-mathura-taxi/ |
   | 10 | same day agra tour from delhi | /en/same-day-agra-tour-from-delhi/ |
4. **Competitor watch:** re-fetch rinocab / 24cabservice sitemaps quarterly — note new URL patterns, copy the structure (never the copy).
5. **Content freshness:** bump the "Fares last updated" month on fare tables whenever prices change; update seasonal pages ahead of season (fog: Nov, Holi: Feb, wedding: Oct, Diwali: Sep).
