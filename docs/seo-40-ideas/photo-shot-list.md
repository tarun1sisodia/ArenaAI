## Rules
- One hero image per landing page, ≥1200px wide, original (never the same file twice).
- Alt text: describe the image literally + location; include the vehicle/route keyword once, naturally.
- Compress to WebP < 150 KB each; lazy-load below the fold (already the site pattern).
